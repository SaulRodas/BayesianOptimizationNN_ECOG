# Material de referencia opcional

Este directorio puede contener fuentes externas o implementaciones antiguas **solo para consulta**, nunca como especificación prevalente. No se incluye código historico en el paquete: puede contener secretos y decisiones incompatibles.

El proyecto se implementa desde cero conforme a `docs/protocolo_implementacion.md`. Si se aportan fuentes a Codex, primero revisar que no contengan API keys, tokens, datos sensibles o salidas de test utilizadas para tomar decisiones.

Para bibliografía y enlaces, consultar `docs/referencias.md`.
