# Resultados

Los resultados experimentales se guardan en Drive y se excluyen de Git. Cada ejecución usa `results/<etapa>/<run_id>/`; desde 02 los reportes registran el mismo `pipeline_id` de los datos preparados.

El EDA es opcional. Sus figuras y tablas no habilitan ni bloquean el preprocesamiento. Las carpetas históricas conservan su formato y no equivalen a una verificación del pipeline actual.

Las evidencias de pruebas locales también se excluyen de Git; nunca equivalen a V01–V14 PASS sobre datos reales.
