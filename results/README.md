# Resultados

Aqui se almacenaran EDA, verificaciones, perfiles de factibilidad, estudios Optuna y evaluación final. Los resultados no se versionan con Git; conservar copias persistentes fuera de Colab, junto con manifiestos y hashes.

La primera entrega usa `implementation_checks/` para evidencia de pruebas sintéticas locales; esa carpeta no equivale a `verification/` ni a aprobación del paso 3. El EDA real escribe en el almacenamiento configurado de Drive: `TT_ECoG/results/eda_qc/<run_id>/`, con decisiones inicialmente pendientes.
